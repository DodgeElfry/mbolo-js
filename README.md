# SAISON 1 : MBOLO JS

## Objectif :

Le but de cette saison est de se familiariser avec la syntaxe de Javascript et typeScript.

### Détails de l'exercice

La saison comprend 13 épisodes :
- Episode 1 : Variable de type chaîne de caractères 
- Episode 2 : Quel est votre nom ?
- Episode 3 : Somme de deux nombres
- Épisode 4 : Permuter les valeurs de deux variables
- Episode 5 : Le double d'un nombre
- Episode 6 : La moyenne de trois nombres
- Episode 7 : Mineur ou Majeur
- Episode 8 : Nom, genre et titre
- Episode 9 : La moyenne d’un élève et sa mention
- Episode 10 : Total à payer et remise
- Episode 11 : Table de multiplication
- Episode 12 : La somme des 10 premiers nombres entiers à partir de 1
- Episode 13 : Renseigner la bonne réponse d’une opération

Nous   n'utilisons   pas   des   bibliothèques   tierces Javascript dans nos programmes. La syntaxe acceptée est celle de ECMAScript 2015.

Tout le code est typé TypeScript (ES2015), indenté,  et commenté.

Les fonctions des épisodes sont importées à partir des fichiers episode-x.ts dans main.ts. Les styles sont importés à partir de style.css dans main.js.

Le fichier index.html charge main.ts avec type="module".

Chaque épisode se lance au clic du bouton correspondant.
